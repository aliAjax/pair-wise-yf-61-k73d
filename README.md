# 远程设备固件分批发布控制台

源提示词摘要：发布负责人选择设备范围、固件版本、分批比例和回滚版本，运维设定兼容条件与失败阈值，值班人员监视下载、安装、重启和异常事件；关键发布支持审批、暂停、继续和紧急回滚，过期状态不可误用。

## 技术栈

Angular、TypeScript、Angular Material、NgRx、Angular Router、RxJS、Angular CDK、Transloco。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62026`

## 可用流程

- 创建发布批次并关联设备分组、固件版本、分批比例和失败阈值。
- 批次从草稿、已审批、发布中、暂停到完成或回滚。
- 兼容条件阻止不合格分组加入发布；实时指标由本地遥测模拟驱动。
- 审批、暂停、继续、回滚和状态变化保留审计记录并持久化到 localStorage。

## 校验码对账规则

- 发布时登记该批发布包/回滚包校验码；每个灰度档真正下发时锁定当时的校验码。
- 设备回执必须携带实装包校验码；与登记值不符的列为**待核实**：不推进下一档、不计入已装台数。
- 同一设备重复上报只保留最新一条（旧条标注作废留痕）；同刻并发提交按全局后到序号裁决。
- 改动发布包校验码：旧回执当场作废，未下发档位清空并按新包重算，已装好的结果（含已封档）保留，回滚仍按旧码覆盖。
- 紧急回滚只覆盖实装校验码命中本批实际下发包的设备；回滚结果按设备记账，失败设备单独重试，成功设备不重复下发。
- 离线规则验证脚本：`scripts/verify-reconciliation.ts`，共 22 个场景。
